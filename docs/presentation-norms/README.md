## Что важнее при расхождении

1. Задание (`Забота о людях.md`, его PDF-оригинал) и правила хакатона (`ПРАВИЛА ХАКАТОНА.pdf`).
2. Сообщения организаторов: регламент финала, отзыв жюри.
3. Правила проекта из `CLAUDE.md`: честность данных, пометка моделируемого.
4. Советы мастер-класса. Это мнение спикера, а не требование организаторов.

Расшифровка и запись мастер-класса хранятся локально и в репозиторий не входят.
