**Реализованный срез — 22.09.2026**

Архитектура этой ветки уточняет ранний дизайн docs/architecture.md:
один Node.js 24+ процесс, официальный SDK MAX 0.3.1, встроенный SQLite,
защищённый HTTP webhook, транзакционные состояние/дедупликация/очередь.
PostgreSQL, React, собственный пользовательский HTTP API и reverse proxy в контейнере
не реализованы. Reverse proxy требуется при реальном внешнем развёртывании.

Тексты ru/en, подтверждение границ сценария, план двух процедур, карточки,
самоотметки документов и фактических дат, напоминания, /stop, /delete и выход к КФУ
доступны в локальном демонстраторе. Черновые нормы блокируют APP_MODE=live.

Изменения правил по аудиту не являются юридическим утверждением:
удалена неподтверждённая переходная ветка, исправлена ссылка на пункт о дактилоскопии,
повторное окно отделено от рекомендуемой даты, добавлено выявленное расхождение
комплекта. Все записи остаются draft.

Изменение версии справочника не переписывает действующий план молча: выдача старого
расчёта и напоминаний останавливается до нового профиля.

Работа с данными: один экземпляр сервиса и одна SQLite БД; ожидающие исходящие сообщения
переживают рестарт. Повтор webhook безопасен; неопределённый сетевой результат MAX
может вызвать дубль сообщения. Нужны мониторинг failed-заданий и резервное копирование.
Масштабирование в несколько реплик требует отдельной реализации владения заданиями.

Оставшиеся блокеры: компетентная проверка правил и источников, оператор данных,
токен и домен, фактический прогон MAX, пользователи/партнёр, презентация, финальная
конфигурация проверки и заморозка сдаваемого коммита.
