# Исследования

Промпты для независимых исследований в ChatGPT по условиям трека. Каждый промпт
самодостаточен: файл из `prompts/` копируется в новый чат целиком.

## Как запускать

- Режим Deep Research или чат с поиском в интернете. Каждый промпт — в новом чате,
  чтобы исследования не влияли друг на друга.
- Результат — в `results/` под тем же номером, например `results/01-patient-journey.md`.
- Каждый результат перед использованием прогнать через `11-fact-check.md` в
  отдельном чате. Непроверенная цифра в презентацию не идёт.
- В чаты не вставлять токены, ключи и реальные персональные данные (в том числе
  расшифровки интервью с именами).
- Техническую часть MAX не исследуем: она в `docs/max-platform.md`.

## Этап 1. Выбор проблемы

Промпты независимы, их можно запускать параллельно.

| № | Файл | Что даёт |
|---|---|---|
| 01 | `prompts/01-patient-journey.md` | Барьеры на медицинском пути пациента, топ-5 проблем |
| 02 | `prompts/02-relocation-migrants.md` | Барьеры после переезда и у иностранцев, изменения правил, топ-5 проблем |
| 03 | `prompts/03-social-support.md` | Барьеры в мерах поддержки, льготах и статусах заявлений, топ-5 проблем |
| 04 | `prompts/04-legal.md` | Правовые рамки: персональные данные, медицина, госуслуги, ИИ |
| 05 | `prompts/05-open-data.md` | Открытые данные и API для MVP, статистика для обоснования |
| 06 | `prompts/06-max-ecosystem-hackathon.md` | Даты и регламент хакатона, что уже есть в MAX, приоритеты ведомств |

## Этап 2. После выбора проблемы

Перед запуском заполнить поля в квадратных скобках. Ответы 07, 09 и 10 приходят
по шаблонам скилла `product-framing` и после фактчекинга переносятся в `docs/product/`.

| № | Файл | Когда | Куда идёт результат |
|---|---|---|---|
| 07 | `prompts/07-problem-validation.md` | Сразу после выбора | `problem.md`, `as-is-to-be.md`, `hypothesis.md` |
| 08 | `prompts/08-competitors.md` | Параллельно с 07 | раздел «Что уже есть» в `problem.md` |
| 09 | `prompts/09-scaling-pilot.md` | После 07 | `scaling.md`, `pilot.md` |
| 10 | `prompts/10-mvp-ux.md` | После 07 | `mvp.md` |
