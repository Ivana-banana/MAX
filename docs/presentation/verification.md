## Что именно проверено

`npm run demo:export:check` сначала выполняет TypeScript build и только затем
импортирует dist. Скрипт отказывается помечать незафиксированные src-изменения
хешем другого коммита. Git подтвердил одинаковый `src` у проверенного 694abca,
замеренного cf6c32e и базы f6e2e9c:
`b78f8f684265452e422bc30ada5cc393c6eb82e9`.

Последовательность экспорта: выбор языка → условия → границы пилота → KZ → дата
01.09.2026 → план → отметка паспорта → одно напоминание → самоотметка 24.09.2026 →
следующий цикл → /stop → подтверждённое удаление. Часы фиксированы явно, SQLite
находится в памяти, доставка заменена сборщиком сообщений. MAX не использовался.

`pdfinfo` показывает 14 страниц без шифрования и JavaScript; `pdftotext -layout`
извлекает русские тексты. Визуально просмотрены все страницы, включая символы
отметок в карточке. Генератор проверяет, помещается ли текст в выделенную область;
внешние картинки не нужны. PDF-ссылки построены из manifest.json.
Негативные прогоны: намеренно изменённая реплика отклонена проверкой transcript;
PDF с добавленными байтами отклонён PDF-check. После этого исходные артефакты
восстановлены и обе проверки снова прошли.
