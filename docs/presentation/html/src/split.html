Устройство и границы

  • Бот и мини-приложение в MAX, одна сессия

  • Явный расчёт сроков по правилам в JSON, без LLM

Границы

  • Учебные профили, нормы юрист не вычитывал

  • Без подачи в МВД и системы вузов
  • Поступление и гранты не реализованы, это исследование
