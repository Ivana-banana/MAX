## Как показывать

- `→`, `Space`, `PageDown` или клик справа — дальше; `←`, `PageUp` или клик в левой
  трети — назад; `Home` и `End` — первый и последний слайд.
- `F` — полный экран. Номер слайда хранится в адресе (`classic.html#4`).
- PDF: `Ctrl+P` → «Сохранить как PDF», поля «Нет», «Фон» включён. Получается один
  слайд 16:9 на страницу.

## Сборка

Из корня репозитория:

```sh
npm ci --ignore-scripts && npm run build
npm run web:install && npm run web:build
node docs/presentation/html/screens.mjs      # экраны в screens/, нужен Playwright Chromium
node docs/presentation/html/build.mjs        # все src/*.html → *.html; или build.mjs classic
```

Исходники — `src/<вариант>.html`, общие `src/base.css` (сцена 1920×1080, печать) и
`src/deck.js` (переключение слайдов). Шрифты в `fonts/` — под SIL OFL 1.1, тексты
лицензий лежат рядом.

Облик мини-приложения у `classic` лежит отдельно от текста, в `src/classic-look.css`: зерно
бумаги (`src/grain.png`) и фото вузов в красном дуотоне с растром, круг, кольцо и вертикальное
название города на титуле, слайде «От КФУ к другим вузам» и заключении. Фото те же, что в
мини-приложении: `web/src/photos/` (Public Domain и CC0, источники — `SOURCES.md` там же).
Остальные картинки `classic` — в `src/img/` (источники и лицензии — `src/img/SOURCES.md`):
карта центра Казани из OpenStreetMap (ODbL, подпись на слайде), Спасская башня на слайде
«Бот напоминает сам», Деревня Универсиады на пилоте и маленькие фото вузов у столбиков
масштаба. Аватарки команды в том же дуотоне — `src/team/`.

Те же слайды и текст `classic` в другой раскладке — скины `src/skins/classic-<скин>.css`,
`build.mjs` собирает их последними поверх `classic`:

- [`classic-poster.html`](classic-poster.html) — «Плакат»: вторая строка заголовка
  кармином и красная планка над ним, вертикальная подпись справа, крупные номера; на титуле
  Казань снизу под диагональю, в заключении — справа.
- [`classic-night.html`](classic-night.html) — «Ночь»: тёмная тема мини-приложения, красная
  полоса с подписью слева; Казань на весь титул и снизу под диагональю в заключении.

Сборка одного скина: `build.mjs classic+poster`.
