# Презентация финала: HTML-варианты

Черновики презентации финала 29.10.2026 (#38, D-073). Каждый вариант собран в один
HTML-файл: шрифты, стили, скрипт и экраны встроены, файл открывается без сети двойным
щелчком.

| Файл | Сюжет и стиль | Статус |
|---|---|---|
| [`classic.html`](classic.html) | Классика D-069 → «Плакат»: стиль мини-приложения, Tektur и PT Sans | образец на выбор |

Остальные пять вариантов (путь студента, показ в центре, было → стало, ответ жюри,
глазами вуза) собираются после выбора стиля по образцу.

## Как показывать

- `→`, `Space`, `PageDown` или клик справа — дальше; `←`, `PageUp` или клик в левой
  трети — назад; `Home` и `End` — первый и последний слайд.
- `F` — полный экран. Номер слайда хранится в адресе (`classic.html#4`).
- PDF: `Ctrl+P` → «Сохранить как PDF», поля «Нет», «Фон» включён. Получается один
  слайд 16:9 на страницу.

## Пометки «заменить»

Розовые плашки на экранах — черновые картинки, их нужно заменить до сдачи:

- «Рендер из кода, заменить на скриншот MAX» — мини-приложение, снятое `screens.mjs` в демо-режиме на учебных
  данных (Pixel 7, светлая тема). Это не снимок MAX: на экране видна строка «Запуск без
  подписи MAX». Нужен скриншот из MAX (#33).
- «Скриншот MAX от 27.09» — старый скриншот из `../screens/`, версия до онлайн-сдачи.

## Сборка

Из корня репозитория:

```sh
npm ci --ignore-scripts && npm run build
npm run web:install && npm run web:build
node docs/presentation/html/screens.mjs      # экраны в screens/, нужен Playwright Chromium
node docs/presentation/html/build.mjs        # все src/*.html → *.html; или build.mjs classic
```

Исходники — `src/<вариант>.html`, общие `src/base.css` (сцена 1920×1080, печать) и
`src/deck.js` (переключение слайдов). Шрифты в `fonts/` — под SIL OFL 1.1, тексты
лицензий лежат рядом.

Раскадровка выступления по вариантам — [`storyboard.md`](storyboard.md).
