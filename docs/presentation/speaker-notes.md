источники — для проверки; основной рассказ — слайды 2–14. Хронометраж пока не измерен.

## Если не работает интернет

PDF открывается локально. Показывать его как сохранённый материал, а не имитировать
живую отправку. Локальное демо запускается по README после предварительной загрузки
Docker-образа; сеть для уже собранного консольного сценария не нужна.
Запасной вариант показа MAX — скриншоты в `images/max-check/` (протокол 27.09). Видео
прогона пока нет.
