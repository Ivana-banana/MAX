## Если не работает интернет

PDF открывается локально. Показывать его как сохранённый материал, а не имитировать
живую отправку. Запасной показ MAX — скриншоты на слайдах 11–12 (версия 25–27.09) и в
`images/max-check/`. Видео прогона пока нет. Локальное демо запускается по README после
предварительной загрузки Docker-образа; сеть для уже собранного консольного сценария
не нужна.
