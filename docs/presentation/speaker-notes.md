# Заметки докладчика

Черновая репетиция на 4–5 минут, не утверждённый регламент. Служебный слайд и
источники — для проверки; основной рассказ — слайды 2–13. Хронометраж пока не измерен.
Прогон с человеком вне команды и распределение ролей ещё предстоят.

## Если не работает интернет

PDF открывается локально. Показывать его как сохранённый материал, а не имитировать
живую отправку. Локальное демо запускается по README после предварительной загрузки
Docker-образа; сеть для уже собранного консольного сценария не нужна.
Видео реального MAX пока нет. После mobile/web-прогона записать его с указанием
commit, даты, платформы и синтетического профиля.
