# Стиль текстов интерфейса

Правила для `src/data/i18n/ru.json` (#119). Перевод на другие языки повторяет смысл и
разметку русского текста (#114, тест разбивки в `tests/i18n.test.ts`).

## Что можно менять

Только формулировку. Каждый факт, подстановка `{…}`, оговорка и источник остаются на своём
экране. Разметка не меняется: жирный, курсив, абзацы, пункты «•».

## Правила

1. **Без канцелярита.** Глагол вместо отглагольного существительного: «бот не считает
   сроки», а не «расчёт не выполняем». Без цепочек родительных падежей.
2. **Одна мысль — одно предложение.** В скобках только короткие уточнения: дата, источник,
   пример формата.
3. **Голос.** О себе бот говорит в третьем лице: «бот посчитает», «бот не оценивает».
   Короткие статусы — безлично: «PDF готовится…».
4. **Обращение** на «вы», со строчной буквы.
5. **Род нейтральный.** «Я учусь в {uni}», а не «я иностранный студент»; «У меня отрывная
   часть», а не «получил(а)». «(а)» — только если иначе не помещается на кнопке.
6. **Сокращения** раскрываются, если фраза от этого не разваливается; общепринятые («МВД»,
   «вуз», «PDF») остаются.
7. **Типографика.** Тире «—» с пробелами, кавычки «ёлочки», буква «ё», дата в примере —
   ДД.ММ.ГГГГ. Команда в конце сообщения — отдельной строкой: «/plan — отмена».

## Словарь

Одно понятие — одно слово. Юридические термины — как в законе.

| Понятие | Пишем | Не пишем |
|---|---|---|
| Последний день, посчитанный ботом | предельный срок; «расчётный предельный срок» — там, где больше ничто на экране не говорит, что дату посчитал бот (карточка, черновик письма вузу, напоминание о просрочке) | расчётный срок, крайний срок |
| Срок из правил вуза | срок {uni}, срок по правилам {uni} | {uni} просит раньше |
| Срок из закона | срок по закону | — |
| Отметка студента о пройденном | отметка; оговорка — «с ваших слов» | самоотметка, отметка студента |
| Что взять с собой | список документов | комплект, перечень |
| Дата проверки источника | сверено {date}; отдельной строкой — «Источник сверен: {date}» | сверка {date}, Сверка источника |
| Статья закона, на которой стоит срок | норма | — |
| Время напоминаний | МСК — сразу видно, что это время | по Москве, по московскому времени |
| Напоминания в чате | напоминания бота | уведомления бота |
| Учебные данные демо | учебные данные, учебный профиль; в PDF — «УЧЕБНЫЕ ДАННЫЕ» капсом | демонстрационные данные |
| Юридическая проверка норм | юрист ещё не проверил нормы | нормы не вычитаны юристом |
| Миграционный учёт | миграционный учёт (регистрация) — процедура; уведомление о прибытии — документ, его подаёт принимающая сторона; отрывная часть уведомления — что получает студент | — |
| Не официальный ответ | не решение МВД | — |
