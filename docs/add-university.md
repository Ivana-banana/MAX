# Как подключить вуз

Новый вуз — это **один файл данных** `src/data/universities/<id>.json`. Код, диалог,
мини-приложение и расчёт сроков не меняются: федеральные нормы лежат отдельно в
`src/data/rules/`, и профиль вуза не может их ослабить — полей срока у профиля нет.

Кто делает: сотрудник, у которого есть доступ к официальным страницам вуза. Нужны
владелец данных в вузе (кто сообщит об изменениях), переводчик или проверенный машинный
перевод (`D-024`) и тот, кто прогонит сценарий в MAX.

## 1. Собрать источники

Только официальные страницы самого вуза — не памятки агентств, не чужие репозитории и не
пересказы. Для каждой страницы записать адрес и дату сверки. Нужны:

- страница контактов по визам и миграционному учёту — в неё ведут «Не получилось» и
  «Открыть страницу вуза»;
- если вуз сам публикует порядок процедуры (например, миграционный учёт при заселении в
  общежитие) — страница с этим порядком, местом, документами и сроком словами вуза.

## 2. Создать файл профиля

`id` — латиница в нижнем регистре, цифры, `_` и `-`, до 32 символов. Он же попадает в
диплинк `max.ru/<бот>?start=<id>` и в QR-плакат.

| Поле | Что писать | Проверка при загрузке |
|---|---|---|
| `id` | короткий идентификатор, например `spbu` | формат, уникальность в каталоге |
| `name` | несклоняемое краткое название на **всех** языках интерфейса (`ru`, `en`, `uz`, `zh`): его вставляют в фразы вида «общежитие КФУ» | непустое; бот не запустится, если языка не хватает |
| `contactUrl` | официальная страница контактов | только `https://` |
| `citizenships` | коды ISO из двух букв — кнопки гражданств, для которых сценарий подходит | не пусто; гражданства, которые нормы исключают (сейчас `BY`), запрещены |
| `checkedAt` | дата сверки контактов, `ГГГГ-ММ-ДД` | формат даты |
| `procedures` | необязательно: процедуры вуза без расчётного срока (`D-034`) | см. ниже |

Процедура в `procedures`: `id` (не совпадает с id нормы), `title`, `action` (что сделать,
куда прийти), `when` (срок **словами источника** — бот его не считает и не напоминает),
`documents` (`id` + `title`), `appliesIf` (пустой массив — для всех, или
`{"field": "citizenship", "op": "in" | "notIn", "values": [...]}`) и `source`
(`url` на `https://`, `checkedAt`). Все тексты — на всех языках интерфейса.

Образцы — `kfu.json`, `itmo.json` и `spbgeu.json` (все с процедурами). Профиль без процедур тоже допустим:
тогда блока «Без расчётного срока» у вуза нет. Поле `$comment` — для людей:
кто этот вуз для проекта (партнёр или нет) и откуда данные.

## 3. Проверить

```sh
npm run university:check
```

Команда загружает нормы, профили и тексты так же, как бот при запуске, и печатает для
каждого вуза языки названия, диплинк, контакты, гражданства, процедуры и пример плана.
Код выхода 1 и строка с файлом и полем — профиль, с которым бот не запустится.
Предупреждения (не ошибки): контакты или источник процедуры сверены больше 180 дней назад;
гражданство, для которого не применяется ни одна норма (студент получил бы пустой план).

```sh
npm test
```

`tests/catalogue.test.ts` сам находит новый профиль и проходит сценарий для каждого его
гражданства на граничных датах въезда и на каждом языке: план построен, вопрос вузу
называет **этот** вуз и ведёт на его страницу, процедуры без срока — только из этого
профиля, в текстах нет незаполненных `{подстановок}`. Имена вузов в тесте не записаны —
править его не нужно.

## 4. Выпустить

1. Коммит с профилем → CI зелёный → выкатка (`docs/deploy.md`, «Обновление»).
2. `npm run build && npm run qr <id>` — QR-плакат A4 с диплинком и текстами на всех языках.
3. Прогон в MAX по `docs/max-manual-check.md` с диплинком нового вуза и через кнопку
   «🏫 Я из другого вуза» — в мобильной и веб-версии; результат — в протокол проверки.
4. Записать, сколько часов заняла адаптация и какие файлы изменились: это доказательство
   переноса для раздела масштабирования (`docs/product/scaling.md`).

## Чего профиль не делает

- Не меняет федеральные сроки и перечень процедур — это `src/data/rules/` и юридическая
  вычитка (`docs/legal-review.md`).
- Не превращает вуз в партнёра: пока нет договорённости, в `$comment` и в материалах
  вуз — «не партнёр».
- Не подключает интеграции с системами вуза: ссылки — публичные страницы.
