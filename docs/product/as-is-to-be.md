# Текущий и предлагаемый путь

Статус: модель для проверки наблюдением; измерений пока нет.

## As Is

| Этап | Действие | Источники / данные | Возможная потеря | Что вручную |
|---|---|---|---|---|
| Найти инструкцию | Открыть сайт, спросить куратора | Сайт КФУ, канал куратора | Поиск применимого раздела | Сопоставление ссылок |
| Определить свою ветку | Учесть жильё, статус, обстоятельства прибытия | Ответы студента, официальные правила | Чужая ветка может выглядеть подходящей | Выбор правил |
| Подготовиться | Проверить наличие требуемых документов | Актуальный перечень подразделения | Незамеченный недостающий пункт | Личный список |
| Обратиться | Прийти/использовать установленный канал | Контакты, время работы | Неясность готовности | Возврат к памятке |

Точка воздействия: подготовка к первому обращению. Частота потерь и повторных визитов
не установлена; это вопросы исследования, а не аргументы с измеренным эффектом.

## To Be

| Было | Предлагаемое изменение | Тип |
|---|---|---|
| Самостоятельный выбор ветки | Несколько вопросов и объяснение применимости | Упрощается |
| Личный список | Сохранённый чек-лист с источником и отметками | Упрощается |
| Неясно, чего не хватает | Система показывает недостающие пункты по ответам | Автоматический расчёт |
| Возврат к нескольким страницам | Карточка ближайшего действия с официальной ссылкой | Быстрее |
| Забытый незавершённый шаг | Согласованное напоминание возвращает в нужную карточку | Автоматически |

Пользователь получает сохранённый и объяснимый результат подготовки. Само обращение,
юридическая проверка и постановка на учёт остаются в установленном официальном процессе.
