## Статус в sources.json

Добавлены цитаты к страницам, которые уже есть в `src/data/sources.json`:
`int.itmo.ru/ru/important_documents` (виза, RuID), страница отдела СПбГЭУ (приглашение),
страница КФУ о медосвидетельствовании (перевод паспорта, прежние обследования).

Новые страницы (`kpfu.ru/invitations`, страница RuID КФУ, `shablony-perevodov`,
`priem-inostrannyh-grazhdan-4726.html`, `int.itmo.ru/ru/bachelors_programs`,
`int.itmo.ru/ru/masters_programs`, `unecon.ru/priem/vopros-otvet/`, страница общежитий
СПбГЭУ) в `sources.json` не добавлены. Тест `tests/sources.test.ts` («keeps no source
nobody uses any more») требует, чтобы каждая страница в `sources.json` была ссылкой из
норм или профилей вузов. Эти страницы появятся там, когда этап «до въезда» войдёт в
данные бота. Страницы `education-in-russia.com` собраны на JavaScript: `sources:check`
видит только пустую оболочку, цитату проверить нельзя.
