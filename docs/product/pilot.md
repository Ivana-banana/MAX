# Пилот

Статус: предложение; договорённостей, интервью и набранных участников нет.

| Вопрос | Предлагаемый ответ |
|---|---|
| Где и для кого? | Одна группа совершеннолетних иностранных первокурсников одного вуза; КФУ — первый кандидат |
| Как встроиться? | Ссылка на бота в уже существующей памятке/канале куратора после согласования с владельцем |
| Кто нужен? | Сотрудник миграционного сопровождения для проверки правил; куратор для набора; исследователь; технический ответственный |
| Какие данные? | Публичные инструкции и минимальные ответы пользователя; на исследовании — синтетические задания |
| Нужен ли ведомственный API? | Для результата подготовки — нет; официальные действия проходят по установленному каналу |
| Как измерить? | Время, корректность плана, самостоятельное завершение; повторные обращения — только при учёте партнёром |
| Размер? | Сначала 10–15 наблюдаемых сессий; затем ориентир 30–50 участников реального пилота, если есть набор и основания |
| Следующий шаг? | Решение о втором вузе после достижения целей, отсутствия критичных ошибок и подтверждения владельца данных |

До реальных пользователей определить оператора данных, состав, основания обработки,
сроки хранения и удаления, размещение и доступ. MAX ID также не считаем анонимными
данными. Конкретный правовой режим утверждается отдельно; эта схема не является
заключением о соответствии законодательству.

Если партнёра не нашли, провести наблюдаемый тест по публичной инструкции. В защите
назвать его исследованием удобства, а не внедрением; не приписывать вузу участие.
Отсутствие договора о пилоте не отменяет независимую проверку правил компетентным
специалистом. Без такого проверяющего можно исследовать понятность интерфейса на
учебном задании, но нельзя утверждать корректность персональной подготовки. Доступ
к проверяющему — обязательное условие перехода к нормативному сценарию продукта.

По времени учитывать сезонность: к октябрю первичное прибытие части студентов уже
завершится. Набирать недавних первокурсников для ретроспективных интервью, отдельно
отмечая искажения памяти; реальный пилот — на доступной группе прибывающих. Не
обещать измерить полный миграционный результат за время одной демонстрации.
