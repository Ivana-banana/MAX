# Ручной проход основного сценария в MAX

Без этой записи допуск под риском: условия требуют, чтобы сценарий проходился в
настоящем MAX **и в мобильной, и в веб-версии**. Данные сервера
(`docs/verification-2026-09-23.md`) этого не заменяют. Проход занимает около 10
минут на одну версию.

## Перед началом

- Бот: [max.ru/t149_hakaton_max_bot](https://max.ru/t149_hakaton_max_bot).
- Commit на сервере: `/health` его не показывает (только `status`, `mode`, `queue`) —
  взять у Ивана или из последней записи о выкатке в `HANDOFF.md`, раздел «Деплой».
- Если уже проходили сценарий раньше — сначала `/delete` → «Да, удалить». После смены
  версии правил старый профиль останавливается сообщением «Правила изменились» —
  так задумано.
- Мобильная и веб-версия — **разные прогоны**. Можно одним аккаунтом: между ними
  `/delete`.
- Скриншот на каждом отмеченном 📷 шаге: они нужны для презентации (слайды со
  сценарием). Складывать в `images/max-check/<mobile|web>-<шаг>.png`. На скриншотах не
  должно быть чужих имён и номеров телефонов.

## Сценарий

Даты: сегодня — день прохода; дата въезда — **2026-09-01** (или любая с 01.09 по
сегодня). В демо отвечаем за учебного персонажа, свои данные не вводим.

| # | Действие | Ожидается | Моб. | Веб |
|---|---|---|---|---|
| 1 | Открыть бота, «Начать» или `/start` | «Выберите язык / Choose your language», кнопки «Русский» и «English». Сверху плашка «ДЕМО · учебные данные, нормы не утверждены.» 📷 | | |
| 2 | «Русский» | Текст о хранении данных, кнопки «Продолжить» и «Удалить / выйти» | | |
| 3 | «Продолжить» | Границы сценария (18+, первый въезд для учёбы, общежитие КФУ…), кнопки «Да, совпадает» и «Нет / не уверен» | | |
| 4 | «Да, совпадает» | «Выберите гражданство учебного профиля.», кнопки стран | | |
| 5 | «KZ» | «Дата въезда в формате ГГГГ-ММ-ДД…» | | |
| 6 | Ввести `2026-13-01` | «Дата вне сценария или неверный формат…», шаг не сбрасывается — **состояние ошибки** 📷 | | |
| 7 | Ввести `2026-09-01` | «Ваш план подготовки»: медосвидетельствование и дактилоскопия с датами, статус «скоро» или «есть время», строка «Покрыты только две процедуры…» 📷 | | |
| 8 | Кнопка «Медицинское освидетельствование» | Карточка: предельный срок, рекомендуемая дата (если есть), комплект документов с отметками, основание «ФЗ-115, ст. 5, п. 18…», дата сверки 📷 | | |
| 9 | Отметить документ «Паспорт» | Отметка появилась у документа; после «К плану» и возврата в карточку сохранилась | | |
| 10 | «Процедура пройдена» → `/today` | В плане процедура «отмечено вами» | | |
| 11 | «🔔 Включить напоминания» (первая кнопка под планом) | «Напоминания: включены», кнопка сменилась на «🔕 Выключить напоминания» и ушла под процедуры | | |
| 12 | «Не получилось / помощь» | Шаблон вопроса для КФУ с пропусками, `/start` и `/delete` в конце | | |
| 13 | Нажать старую кнопку из шага 4 | «Кнопка устарела. Откройте /plan или /start.» — ничего не ломается | | |
| 14 | `/delete` → «Да, удалить» | «Данные и ожидающие сообщения удалены…» | | |
| 15 | `/start` → «English», пройти 2–7 | Тот же план на английском | | |
| 16 | `/delete` → «Да, удалить», затем открыть ссылку [max.ru/t149_hakaton_max_bot?start=itmo](https://max.ru/t149_hakaton_max_bot?start=itmo) | Экран границ сценария: «общежитие ИТМО»; в карточке — «уточните у ИТМО» и ссылка int.itmo.ru. Если открылся КФУ — записать ❌: `payload` не дошёл (проверить, приходит ли `bot_started` уже знакомому боту). Запасной путь — ввести `/start itmo` 📷 | | |
| 17 | Там же, первый экран | Если язык телефона или браузера русский или английский — сразу экран хранения данных на этом языке и кнопка смены языка; иначе — выбор языка | | |
| 18 | В поле ввода набрать «/» (после `node dist/commands.js` на сервере) | Подсказки `/start`, `/plan`, `/help`, `/stop`, `/delete` с описаниями на русском и английском; `/plan` открывает план 📷 | | |

Если шаг не совпал с «Ожидается» — в ячейку ❌ и одну строку о том, что видно
на экране. Не исправлять на месте и не проходить дальше «чтобы досмотреть»: записать
и сообщить в чат команды.
