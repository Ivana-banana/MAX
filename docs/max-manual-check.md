# Ручной проход основного сценария в MAX

Без этой записи допуск под риском: условия требуют, чтобы сценарий проходился в
настоящем MAX **и в мобильной, и в веб-версии**. Данные сервера
(`docs/verification-2026-09-23.md`) этого не заменяют. Проход занимает около 10
минут на одну версию.

## Перед началом

- Бот: [max.ru/t149_hakaton_max_bot](https://max.ru/t149_hakaton_max_bot).
- Commit на сервере: поле `commit` в `curl -s https://81-26-178-75.sslip.io/health`
  (с выкатки `8bcb1cd` 28.09).
- Если уже проходили сценарий раньше — сначала `/delete` → «Да, удалить». После смены
  версии правил старый профиль останавливается сообщением «Правила изменились» —
  так задумано.
- Мобильная и веб-версия — **разные прогоны**. Можно одним аккаунтом: между ними
  `/delete`.
- Скриншот на каждом отмеченном 📷 шаге: они нужны для презентации (слайды со
  сценарием). Складывать в `images/max-check/<mobile|web>-<шаг>.png`. На скриншотах не
  должно быть чужих имён и номеров телефонов.

## Изменения 28.09 — проверить после выкатки

Проверять **в мобильном MAX и в web.max.ru** на одном и том же выкаченном commit — том,
что пойдёт в сдачу. Перед началом: `curl -s https://81-26-178-75.sslip.io/health` —
поле `commit` должно совпасть с `git rev-parse origin/main` (выкатка по разделу
«Обновление» `docs/deploy.md` передаёт его серверу). Поля нет — выкатка сделана старой
командой: сверить бандл мини-приложения — на этом commit `npm run web:build` и сравнить
имя `assets/index-*.js` в HTML главной страницы сервера с `web/dist/assets/`. Не
совпало — прогон не начинать.

Мини-приложение открывается кнопкой MAX у поля ввода чата. Кнопка «📱 План в
мини-приложении» под планом есть, только если на сервере задан `WEBAPP_BOT`; где в шагах
она упомянута, без неё открывать приложение кнопкой у поля ввода.

Шаги 1–24 повторять для основного сценария не нужно. Для новых шагов использовать
учебный профиль КФУ: язык интерфейса MAX — русский, гражданство Казахстан, въезд
`01.09.2026`.

Если до удаления есть профиль на старой версии норм, сначала выполнить условный шаг 25;
