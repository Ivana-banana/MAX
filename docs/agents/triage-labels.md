Метки GitHub Issues (создаёт `bash scripts/issues.sh labels`):
`P0` — до финала обязательно; `P1` — даёт баллы, до финала; `P2` — после ответа юриста
или после финала; `area:*` — область; `needs-human` — агент не сделает; `blocked` —
ждёт внешнего ответа; `blocker` — риск показа на финале, закрыть раньше своей задачи.
