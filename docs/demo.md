# Демонстрация и защита

На 22.09.2026 доступно локальное демо. Сценарий в MAX mobile/web не проверен:
нужны токен и HTTPS. КФУ — кандидат для пилота, партнёрства и интервью пока нет.
Все нормы draft; выводы демо не выдаются за подтверждённые юридические сроки.

## Локальная репетиция — около 3 минут

Запуск: `docker compose up --build -d`, затем
`docker compose run --rm --no-deps bot node dist/demo.js --script`.
Интерактивный вариант после установки и сборки: `npm run demo`.
Скриптовое демо явно использует учебную дату **24.09.2026** и БД в памяти.
Оно выводит пометки `[MOCKED: MAX delivery]` и не отправляет сообщения в MAX.

| Шаг | Действие | Объяснение | Наблюдаемый результат |
|---|---|---|---|
| 1 | /start, русский, условия, подтверждение границ пилота | «Проверяем узкий учебный сценарий первого въезда» | Вопрос о гражданстве |
| 2 | KZ, дата 01.09.2026 | «Это синтетический профиль; нормы ещё не прошли независимую вычитку» | Две процедуры, расчётные даты 30.09 и 29.11 (D-016) |
| 3 | Карточка медосвидетельствования, отметка документа | «Есть перечень подготовки и ссылка на основание» | Чек-лист, источник, дата проверки, демометка |
| 4 | Включить напоминания | «Очередь хранится в SQLite; сегодня в учебном времени — за 7 дней до срока» | Одно напоминание; повторный проход очереди его не дублирует |
| 5 | Процедура пройдена, 24.09.2026 | «Это самоотметка пользователя, без проверки в реестре» | Новая рекомендуемая дата и конец расчётного окна |
| 6 | /stop | «Пользователь управляет уведомлениями» | Ожидающие напоминания отменены, профиль сохранён |

Для настоящего показа использовать тот же путь через кнопки MAX. Напоминание
показывать в реальное подходящее время; не выдавать ускоренные или подменённые часы
за настоящую доставку. Дату, commit, клиент и результат записать в протокол проверки.
Дополнительно вручную проверить /delete с подтверждением, неверную дату и возврат
через /start после перезапуска. Регламент защиты и распределение ролей — TBD.

## Запасной план

До готовности MAX терминал служит только репетицией, не доказательством допуска.
После успешного прогона снять видео mobile/web с указанием commit. Для защиты:
запасной интернет, второй телефон, видео и скриншоты в приложении к презентации.
Видео и скриншоты MAX пока не созданы. Черновая [PDF-презентация](presentation/first-90-days.pdf)
и [вывод локального кода](presentation/demo-transcript.json) доступны; это не запись MAX.
После изменения сценария обновить материалы по [инструкции](presentation/README.md).

## Вопросы жюри

| Вопрос | Ответ | Опора |
|---|---|---|
| Чем отличаетесь от существующих сервисов? | Базовые статусы и напоминания уже есть у других университетов. Проверяем гипотезу, что ясный маршрут подготовки и помощь при срыве шага снижают число неполных обращений. Преимущество пока не доказано. | audit-2026-09-22.md, product/next-steps.md |
| Откуда известно, что проблема есть? | Есть расхождения в опубликованных памятках; это повод для проверки. Интервью и наблюдение за задачей ещё предстоят, измеренного эффекта нет. | product/problem.md |
| Что настоящее, что смоделировано? | Расчёт, диалог, хранилище и очередь выполняются локально. Доставка MAX в демо заменена консолью; внешние реестры не подключены. | README, verification-2026-09-22.md |
| Почему бот? | Для короткой анкеты, плана и напоминаний хватает последовательного диалога. Мини-приложение пока не оправдано измеренной потребностью. | decisions.md |
| Как переносить в другой вуз? | Правила уже в JSON. Контакты, границы пилота и тексты ещё связаны с диалогом; перед вторым вузом их нужно отделить. | product/scaling.md |
| Что если MAX недоступен? | Состояние и ответы сохраняются транзакционно; очередь повторяет отправку до 8 попыток. Failed виден в /health. Неопределённый сетевой ответ может приводить к дублю сообщения. | README |
| Что с данными? | Сейчас только синтетические профили, без паспортов и медицинских файлов. Есть /delete и срок очистки; условия реального пилота и обработка резервных копий ещё требуют определения. | README |
| Где пилот и эффект? | КФУ — кандидат, не подтверждённый партнёр. Сначала проверяем спрос и качество маршрута; автоматизация не доказывает социальный эффект. | product/next-steps.md |

Перед защитой провести репетицию с человеком вне команды и записать хронометраж.
