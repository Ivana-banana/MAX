   иначе тесты покажут `vitest: command not found` (`GIT.md`).
3. Файлы менять только в своём worktree (`GIT.md`), в `main` — через
   `git push origin HEAD:main`.

## Как устроен код

Чтобы не читать всё подряд. Подробно — `docs/architecture.md`.

- `src/core/dates.ts` — арифметика календарных дат без времени и часовых поясов.
  Намеренно не `Date` с временем: иначе результат зависел бы от таймзоны сервера.
- `src/core/types.ts` — контракты. Ни одной страны, процедуры или вуза: всё это данные.
- `src/core/deadlines.ts` — движок: применимость правила, дата срока, план, даты
  напоминаний. `DUE_SOON_DAYS = 7`, `REMINDER_OFFSETS = [7, 3, 1]`.
- `src/data/rules/ru-student.json` — нормы со ссылкой на акт, редакцией и датой сверки.
  **Все сейчас `status: draft`.** Миграционный учёт сознательно не включён: нет
  проверенного источника по сроку для студентов.
- `src/data/loadRules.ts` — валидация данных при загрузке. `approved` без `reviewedBy`
  не проходит.
- `src/bot/` — диалог, webhook, очередь, транспорт SDK MAX; `src/db/` — схема PostgreSQL,
  хранилище, одноразовый импорт прежней SQLite.
- `src/demo.ts` — локальная учебная демонстрация; `src/main.ts` — сервер.
- `tests/` — 207 тестов. Есть тест, который требует, чтобы все нормы были `draft`:
  после юридической вычитки он упадёт, и статус нельзя будет поменять молча.

Команды: `npm test`, `npm run typecheck`, `npm run build`.
